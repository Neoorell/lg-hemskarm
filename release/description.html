Egen hemskärm med bakgrundsbild, klocka, väder, HDMI och dina appar. Öppnas med HOME.

Efter första installationen: kör sh /media/developer/apps/usr/palm/applications/se.minhemskarm.launcher/setup/setup.sh som root för att koppla HOME-knappen. Senare uppdateringar behöver inte det.

Mer information: https://github.com/Neoorell/lg-hemskarm
